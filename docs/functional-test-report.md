# 功能复核记录

后续完整的网页功能、UI、多屏和组件复核见[网页验收报告](web-acceptance-report.md)，包含本轮新增缺陷、修复和截图。

日期：2026-10-29。范围：本地 H5 生产构建；不代表线上已更新。

## 已修复

- 数的分解在总数为 2 时，候选范围只有三个数却强求四个选项，导致无限循环。改为从有限候选池抽取。
- 英语、拼音练习完成后未计入学习记录；数学练习与闯关未更新数学分项。数学按实际已答题记录，英语、拼音在完成整组时保存。
- 连续打卡不递增，进入首页提前覆盖学习日期。保留上次答题日期，实际答题时更新连续天数。
- 重置仅浅拷贝默认进度，嵌套计数会污染默认值。每次创建独立的初始进度。
- 拼音再次练习时先生成选项再重置索引，可能使用上一轮末题的索引。调整初始化顺序。
- 英语闪卡“认识”记录仅存在页面内存，刷新丢失；切换分类保留旧索引。接入持久化学习记录并重置分类索引。
- 头像选择已保存，但首页、个人页、设置页仍固定显示熊猫。改为显示已选头像，兼容旧的默认表情值。
- 声音开关与自动朗读数学题没有接入播放逻辑。统一朗读入口接入声音开关，数学题变化时按设置自动朗读；修正设置文案与 README 的字体、音频说明。

## 尚未覆盖与现有边界

- iPhone 真机 / Safari 按要求先跳过；手机宽度的 Chromium 检查不能替代 iPhone 测试。

- 小程序、原生 App、外部 44 个站点的全部交互不在本轮验收范围；外链沿用已有访问核验记录。
