## 浏览器流程

完整机器结果：[browser-results.json](screenshots/browser-results.json)。

1. 原学习首页新增入口，保留学习模块。
2. 家长 PIN 设置、恢复码保存确认与进入。
3. 通过编辑器创建审核/自助周期任务和步骤。
4. 儿童提交不提前发星，待审核不再显示打卡按钮。
5. 自助确认先保存，再显示可跳过反馈。
6. 儿童模式后重新验证；家长审批仅发星一次。
7. 奖励价格编辑、自定义生活奖励，不篡改任务历史。
8. 装扮购买、归属及车库保存装备。
9. 现实奖励申请不扣星、批准扣星、取消退款一次。
10. 导出不含 PIN；非法 JSON 不替换数据；恢复并重启后数据一致。
11. 390px 手机、320px 窄屏、1440px 桌面的主要页面无横向溢出。
12. 12 项任务经校验恢复后可滚动、末项可达；0 项自由日正确。
13. 音效和减少动态开关持久化；减少动态时禁用赛车位移动效。
14. 原数学、拼音、英语、闯关路由入口冒烟检查。
15. 损坏原始存储不被覆盖，家长可从有效备份恢复。
16. PIN 恢复不清除成长记录。

领域测试另覆盖星期日、单次日期、跨日和时钟回拨、同名不同次任务、拒绝重做、0 星、全部跳过、历史补审、模板快照、未来日程上限、重复购买与不足余额、兑现不重复扣费、反馈去重、存储故障注入和重试、陈旧写入重读存储、非法备份、管理授权、永久奖杯、v1 增量迁移、外来字段注入及清理存储后禁止复活旧状态。

## 上线前剩余事项

工作区没有微信开发者工具、已登录的微信开发身份、iPhone 或 Apple Safari。需要在对应环境验证小程序导航、SVG 显示、文件选择/分享、前后台 PIN 会话、实际语音和安全区；并在 iPhone Safari 走打卡、审批、兑换和恢复流程。构建和 Chromium 不能代替这两项平台手测。

首发仍为同设备本地数据，不提供远程审批、跨设备同步或严格安全身份认证。现代 H5 使用 Web Locks；缺少该能力的旧引擎只支持单活跃写入页，租约降级不宣称数据库级并发事务。
