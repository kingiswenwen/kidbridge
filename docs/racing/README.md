## 首次使用

1. 从互动学习首页进入今日赛道，首次没有自动安排的现实任务。
2. 家长进入家长中心，设置六位 PIN 并单独保存恢复码。
3. 添加推荐模板或自定义任务，再让孩子按自己的顺序完成并打卡。
4. 家长审核后赛车前进、星星入账；装扮可直接兑换，生活奖励先申请再由家长批准、兑现。
5. 在家长中心“设置与备份”定期导出。当前首发仅同设备保存，不提供账号同步或远程审批。
