# 首页入口与发布验收修复（2026-10-31）

用户反馈：Codex 中打开的线上页面，“第一次来”卡片点不开，成长计划找不到。

本次能确认的实现问题是：原推荐卡片全部指向外部网站并使用 `target="_blank"`，不能作为站内互动功能的快速入口；禁止弹窗的嵌入式窗口无法打开这种入口。无法直接连接用户的 Codex 标签页，因此不把这个实现问题冒充为已确认的用户浏览器根因。当前检查环境也无法直接读取公网源站。

修复：

- “第一次来”改为六个同源、同页打开的站内入口：成长赛道、数学、拼音、英语、数学闯关、奖励仓库。
- 手机和桌面顶栏都明确显示“成长计划”和“互动学习”，首屏保留赛车成长计划直达按钮。
- 外部网站保留在明确标注的资源目录，使用当前页链接并保留复制网址，不要求新窗口。
- 构建给首页与学习入口嵌入同一个发布 SHA。部署成功条件增加实际公网浏览器点击六个入口、页面内容与版本核对，并保留截图；失败沿用现有回退机制。
- SSH/SCP 增加连接与空闲保活限制，避免发布失去连接时无提示长时间挂起。

本地验收：`npm run test:navigation` 对 320/375/1440px 共验证 36 条普通/禁弹窗嵌入式点击路径，检查不产生新窗口、页面内容、数学实际答题与错误；同时检查顶栏与学习首页到成长赛道的入口。成长规则与原有测试保留。完整生产验收结果以对应 GitHub Actions 的 `production-navigation` 产物为准，不以本地测试代替用户环境。
